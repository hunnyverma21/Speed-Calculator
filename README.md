# Speed Calculator

A responsive browser-based calculator that computes average speed from distance and time.

## Features
- Distance units: kilometers, meters, miles, and feet
- Time units: hours, minutes, and seconds
- Results in both km/h and m/s
- Input validation and responsive layout
- Recalculates automatically when values or units change

## Run locally
1. Download or clone this project.
2. Open `index.html` in any modern web browser.
3. Enter a distance and time, then choose the relevant units.

## Formula
`Speed = Distance / Time`

The app converts distance to meters and time to seconds before calculating the result.
